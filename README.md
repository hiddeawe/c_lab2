### Текст задачи

Дан набор целых чисел. Заполнить список L исходными числами и вывести элементы списка L в начале в исходном, а затем в обратном порядке.

Выводим элементы списка в первоначальном порядке с помощью `begin()` и `end()`, затем в обратном порядке с помощью `rbegin()` и `rend()`. Содержимое списка при этом не меняется.

# Задание 2

## Задача 6

### Текст задачи

Даны вектор V и дек D, имеющие четное количество элементов. Добавить в конец вектора первую половин уэлементов дека (в исходном порядке), а в начало дека — вторую половину исходных элементов вектора (в обратном порядке). Использовать два вызова функции-члена insert.

### Алгоритм решения

Вводим два контейнера с чётным количеством элементов: вектор `V` и дек `D`.
Первым вызовом `insert()` добавляем в конец вектора первую половину дека, передавая диапазон от `D.begin()` до середины дека.
Вторым вызовом `insert()` добавляем в начало дека вторую половину исходного вектора в обратном порядке. Для обратного обхода используем `make_reverse_iterator()`. Учитываем исходный размер вектора, чтобы не включить числа, добавленные первым вызовом. Выводим оба результата.

## Задача 7

### Текст задачи

Дан вектор V с четным количеством элементов. Добавить нулевой элемент перед последним элементом в первой половине вектора, совпадающим с каким-либо элементом из второй половины этого же вектора. Если вектор не содержит требуемых элементов, то не изменять его. Использовать алгоритм find_first_of и функцию-член insert.

### Алгоритм решения

Вводим вектор с чётным количеством элементов и делим его на две половины.
Алгоритмом `find_first_of()` ищем элемент первой половины, совпадающий с каким-либо элементом второй половины. Первую половину просматриваем обратными итераторами, поэтому первым найденным совпадением будет последнее совпадение в исходном порядке.
Если элемент найден, переводим обратный итератор в обычный с помощью `base()` и `prev()` и вставляем перед ним ноль функцией `insert()`. Если совпадений нет, оставляем вектор без изменений.

# Задание 6

## Задача 7

### Текст задачи

Дано число K (0 <K< 5) и список L, содержащий не менее 10 элементов. Набор из первых 5 элементов списка скопировать в конец списка, выполнив для этой копии циклический сдвиг на K позиций вправо, а набор из последних 5 элементов исходного списка скопировать в начало списка, выполнив для этой копии циклический сдвиг на K позиций влево. Использовать два вызова алгоритма rotate_copy и итераторы вставки, а также функцию advance.

### Алгоритм решения

Вводим число `K` от 1 до 4 и список, содержащий не менее десяти элементов.
С помощью `advance()` определяем итераторы на начало, середину и конец первых и последних пяти исходных элементов списка.
Первым вызовом `rotate_copy()` копируем последние пять элементов в начало списка, сдвигая их влево на `K` позиций. Результат добавляем через `inserter()`.
Вторым вызовом `rotate_copy()` копируем первые пять элементов в конец списка, сдвигая их вправо на `K` позиций. Для добавления используем `back_inserter()`. Исходные элементы остаются на своих местах, а размер списка увеличивается на десять.

# Задание 8

## Задача 2

### Текст задачи

Дан список L, элементами которого являются английские слова. Получить дек D со строковыми элементами, каждый из которых строится по паре соседних элементов исходного списка L следующим образом: последняя буква правого элемента пары приписывается справа к первой букве левого элемента пары. Количество элементов дека D должно быть на 1 меньше количества элементов списка L. Например, для исходного списка ABC, DEF, KLM, XYZ полученный дек должен содержать строки AF, DM, KZ. Использовать алгоритм adjacent_difference с итератором вставки и функциональным объектом, а также функцию-член erase для дека D.

### Алгоритм решения

Вводим английские слова и записываем их в список `list<string>`. Создаём пустой дек `deque<string>`.
С помощью `adjacent_difference()` последовательно обрабатываем соседние слова. Передаём лямбда-функцию, которая берёт первую букву предыдущего слова через `front()` и последнюю букву текущего слова через `back()`, а затем объединяет символы в строку. Полученные строки добавляются в дек через `back_inserter()`.
Поскольку `adjacent_difference()` первым элементом копирует исходное первое слово, удаляем его из результирующего дека функцией `erase()`. Выводим результат.

# Задание 9

## Задача 2

### Текст задачи

Дан вектор V0, целое число N (> 0) и набор векторов V1, …, VN. Известно, что размер вектора V0 не превосходит размера любого из векторов V1, …, VN. Найти количество векторов VI, I = 1, …, N, в которых содержатся все элементы вектора V0 (с учетом их повторений). Использовать алгоритм includes, применяя его в цикле к двум мультимножествам (контейнерам типа multiset), одно из которых создано на основе вектора V0, а другое на очередной итерации содержит элементы очередного из векторов VI, I = 1, …, N.

### Алгоритм решения

Вводим вектор `V0` и создаём на его основе `multiset`, который хранит числа в отсортированном порядке, сохраняя повторы.
Вводим количество проверяемых векторов `N`. Для каждого очередного вектора создаём своё мультимножество. Алгоритмом `includes()` проверяем, содержит ли оно все элементы мультимножества `V0`, включая необходимое количество повторений каждого значения.
Если проверка успешна, увеличиваем счётчик. После обработки всех векторов выводим количество подходящих.
